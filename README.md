# Unit box

Ниже представлено полное обновлённое описание концепции игры, включая все последние изменения. Описание разбито по файлам и компонентам.

---

├── texture_editor.exe                # Скомпилированный редактор текстур

## 1. Главное меню (`main_menu.exe`)

Отдельное приложение, запускаемое первым. Предоставляет графический интерфейс с кнопками выбора одного из инструментов:

- **Игра** – запускает `game.exe`.
- **Редактор карт** – запускает `editor.exe`.
- **Редактор текстур** – запускает `texture_editor.exe`.
- **Редактор квестов** – запускает `quest_editor.exe`.
- **Редактор модов** – запускает `mod_editor.exe`.

Каждая утилита скомпилирована в отдельный исполняемый файл, что позволяет распространять их независимо и при необходимости заменять/обновлять по отдельности. Главное меню также может содержать настройки графики/звука и краткую информацию о версии.

## 2. Основная игра (`game.exe`)

Это скомпилированное ядро игры, отвечающее за:

- инициализацию Pygame,
- загрузку модулей механик из папки `mechanics/`,
- генерацию мира на основе `world_config.json` и файлов структур,
- главный игровой цикл (обработка ввода, обновление объектов, отрисовка),
- управление камерой, UI инвентаря/здоровья/крафта,
- взаимодействие с внешними модулями механик.

Игровая логика **полностью вынесена** в модули `mechanics/`. В самом `game.exe` нет ни строчки кода конкретных типов объектов – он лишь создаёт экземпляры классов из загруженных модулей, вызывает их методы `update()` и `draw()`.

Основной цикл обрабатывает:

- клики игрока для движения,
- обновление всех объектов (NPC, ресурсы, квесты и т.д.),
- счётчик ходов и смену дня,
- отрисовку пола и объектов с изометрической сортировкой по глубине,
- отображение панели инвентаря, здоровья, еды, кнопок крафта и хранилищ.

## 3. Редактор карт (`editor.exe`)

Скомпилированное приложение для создания и редактирования контента игры.

Режимы редактора:

- **Карта (Map)** – ручное размещение объектов на поле. Выпадающий список содержит все типы объектов из папки `objects/`. Размещение – ЛКМ, удаление – ПКМ.
- **Объекты (Objects)** – создание/редактирование JSON‑конфигов в `objects/`.
- **Рецепты (Recipes)** – управление списком `recipes.json`.
- **Структуры (Structures)** – построение группы объектов с последующим сохранением в папку `structures/`.
- **Настройки мира (World Config)** – настройка спавна структур и одиночных объектов. Сохраняется в `world_config.json`.

## 4. Редактор текстур (`texture_editor.exe`)

Простой графический редактор для создания и редактирования PNG‑текстур, привязанных к объектам.

Принцип работы:

1. Пользователь выбирает JSON‑файл объекта из папки `objects/`.
2. Редактор читает параметры высоты и ширины объекта (в кубиках) и вычисляет размер холста в пикселях под изометрию.
3. Создаётся холст нужного размера, доступные инструменты: кисть, заливка, ластик, пипетка.
4. Готовое изображение сохраняется в папку `textures/` с именем из поля `"texture"` выбранного JSON‑конфига.

## 5. Редактор квестов (`quest_editor.exe`)

Инструмент для создания сценариев в формате JSON, определяющих задания и диалоги для игровых NPC.

Файлы сохраняются в папку `quests/` и включают:

- `id` – уникальный идентификатор квеста.
- `name` – название.
- `description` – описание.
- `initiator` – объект‑инициатор.
- `steps` – массив шагов квеста.
- `next_quest` – ссылка на следующий квест (или `null`).

В игре механика квестов реализована модулем `mechanics/quest.py`.

## 6. Редактор модов (`mod_editor.exe`)

Визуальный конструктор механик для объектов, предназначенный для создания новых типов объектов без ручного написания кода.

Пользователь выбирает базовый тип и добавляет компоненты поведения (движение, блуждание, атака, сбор ресурсов, диалог/квестовая реакция и т.д.).

Редактор генерирует готовый Python‑код класса и сохраняет его в папку `mechanics/`, а также может сгенерировать JSON‑конфиг объекта.

## 7. Модули механик (`mechanics/`)

Ключевые модули:

- `base.py` – базовый класс `GameObject`.
- `wall.py` – статичный объект с коллизией.
- `player.py` – управляемый персонаж.
- `npc_neutral.py` – нейтральный NPC.
- `npc_enemy.py` – враждебный NPC.
- `npc_ally.py` – союзный NPC.
- `resource.py` – ресурсный объект с добычей.
- `storage.py` – контейнер/хранилище.
- `item.py` – модель предметов.
- `craft.py` – логика крафта.
- `quest.py` – логика квестов.

Все модули загружаются динамически через `importlib.import_module()`.

## 8. Папка `objects/`

Содержит JSON‑файлы характеристик объектов (общие параметры, параметры NPC, ресурсов, хранилищ, игрока).

## 9. Папка `structures/`

Хранит JSON‑файлы структур с шансом появления и списком объектов на относительных координатах.

## 10. Папка `quests/`

Содержит JSON‑файлы квестов, которые загружаются модулем `quest.py` при старте игры.

## 11. Файлы `recipes.json` и `world_config.json`

- `recipes.json` – список рецептов крафта.
- `world_config.json` – параметры генерации мира (спавн структур и объектов).

## 12. Взаимодействие всех компонентов

1. **Главное меню** запускает нужную утилиту.
2. **Редактор карт** создаёт объекты, структуры, рецепты и настройки мира.
3. **Редактор текстур** рисует текстуры нужного размера.
4. **Редактор квестов** создаёт цепочки заданий.
5. **Редактор модов** генерирует новые механики.
6. **Игра** загружает конфигурации, генерирует мир и динамически подключает механики.
7. Игрок проходит квесты, сражается, крафтит и взаимодействует с миром, полностью собранным из внешнего контента.

Такая архитектура обеспечивает расширяемость без изменения скомпилированных файлов игры и редакторов.
